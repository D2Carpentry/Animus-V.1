Upload every item in this folder to the root of the ANIMUS-V.1 GitHub repository.

Keep the functions/api/dashboard.js folder path exactly as it is. It adds the
separate Cloudflare snapshot endpoint used by Create Current Backup.

After Cloudflare Pages redeploys, open the Command Center, click the D2
Carpentry & Design profile at the bottom of the left sidebar, and choose
Create Current Backup. The confirmation reports the exact file, revenue,
payroll, and price-line counts that were stored.
