Upload every file in this folder to the main ANIMUS repository.

This adds Contacts below Work Files in the sidebar. Contacts is a live directory made from your existing CRM work files; it does not create a second customer list.

On Contacts:
- Click a name to open that customer's work file.
- Call opens the phone action.
- Text opens the text action.
- Email opens the email action.
- Address opens the location in Maps.
