# ANIMUS

ANIMUS is the D2 Carpentry & Design estimating, dashboard, calendar, revenue, expense, receipt, invoice, and file-management system.

## Main files

- `index.html` - Estimator
- `crm.html` - Dashboard / CRM
- `app.js` - Estimator logic
- `crm.js` - Dashboard logic
- `styles.css` - Shared styling
- `materials-database.js` - Price database
- `dashboard-restore-data.js` - Dashboard seed/restore data
- `revenue-data.js` - Revenue seed/restore data
- `google-apps-script-backend.js` - Google Drive / Calendar script backend

## Storage plan

GitHub hosts the ANIMUS app code. Google Drive / Google Apps Script should be the long-term source of truth for dashboard files, revenue, prices, receipts, and calendar data.
